# Security policy

## Reporting a vulnerability

Please do not open a public issue for a suspected security vulnerability.
Use GitHub's private vulnerability reporting feature for the Paperoll
repository instead. Include reproduction steps, affected versions, impact,
and any suggested mitigation.

You should receive an initial response within seven days. Public disclosure
will be coordinated after a fix or mitigation is available.

## Supported versions

Paperoll is early-stage software. Security fixes are provided for the latest
published release only.
